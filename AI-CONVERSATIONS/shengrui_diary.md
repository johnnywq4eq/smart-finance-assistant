
# 📓 Developer Diary – Shengrui Li

---
Item 1- Project Planning
artifact
Use ChatGPT to assist in brainstorming ideas for the intelligent financial assistant project.
Context
At the beginning of the project, my goal was to develop a financial assistant to help college students better understand their consumption habits and enhance their budget management skills.
Reflection
ChatGPT helped me identify useful financial related features such as expense analysis, budget recommendations, savings recommendations, and CSV transaction processing.
I understand that it is crucial to clearly define business issues before writing code. This allows me to focus on building a system that provides practical financial insights, rather than just displaying raw data.

Article 2- CSV Data Processing
artifact
Use AI to assist in developing Python functions for loading and cleaning CSV transaction data.
Context
The financial assistant needs to handle transaction files that include dates, amounts, categories, and descriptions. These data include real-world issues such as dollar symbols and refund values.
Reflection
ChatGPT used pandas to help generate initial data cleaning logic. I have implemented functions for deleting dollar symbols, converting transaction amounts to numerical values, and deleting invalid rows.
During the testing process, I learned the importance of data cleaning before performing analysis. I have also improved my understanding of DataFrames and CSV processing in Python.


Item 3- Expenditure Analysis
artifact
Developed expenditure analysis functionality using recommendations generated by pandas and AI.
Context
I hope the system can calculate the total expenditure, expenditure by category, average transaction amount, and determine the highest expenditure category.
Reflection
Artificial intelligence helps me build expenditure analysis logic using groupby() and aggregate calculations.
I tested the system with multiple trading scenarios and learned how to generate business centric insights, not just technical outputs.
For example, the system identifies overspending areas such as entertainment or coffee expenses and generates simple financial recommendations based on expenditure patterns.


Project 4- Financial Recommendation System
artifact
Use ChatGPT to generate financial recommendation logic.
Context
This project requires more than just simple calculations. I hope the assistant can provide practical financial advice to users.
Reflection
I have created recommendation logic based on expenditure categories and total expenditure levels.
For example, if entertainment expenses are the highest category, the system will generate recommendations to reduce unnecessary expenses and set monthly limits.
This helped me understand how business logic can improve user experience and make applications more useful to non-technical users.

Article 5- Chatbot Personality Settings
artifact
Use artificial intelligence to create personalized financial chatbots using AI packages.
Context
I hope that intelligent financial assistants can communicate in a friendly and professional manner.
Reflection
ChatGPT helped me design system prompts that focus on simple budget and savings advice.
I have learned how prompts affect the response of chatbots and how artificial intelligence personality can improve user interaction.
During the testing process, I also encountered connection and configuration issues with the artificial intelligence server. I resolved these issues by checking the API configuration and re running the settings cell.
This has improved my debugging skills and understanding of the AI integration workflow.

Article 6- Simple RAG System
artifact
A simple retrieval based financial advice system was constructed using keyword matching.
Context
I hope the chatbot can provide different financial advice based on the user's questions.
Reflection
I implemented a small RAG style system using pre-defined financial prompts and keyword searches.
For example:
Coffee → Savings advice
Food and Grocery → Dietary Plan Suggestions
Transportation → Suggestions for reducing travel costs
Although this system is simple compared to advanced artificial intelligence retrieval systems, it has helped me understand the core idea of Retrieval Enhanced Generative (RAG).
I understand that retrieved context can improve the responsiveness of chatbots and make answers more relevant to user questions.
