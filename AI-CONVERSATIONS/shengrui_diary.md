# 📓 Developer Diary – Shengrui Li

---

## Entry 1 – Project Planning

### Artifact
Used ChatGPT to assist in brainstorming ideas for the Smart Finance Assistant project.

### Context
At the beginning of the project, my goal was to develop a financial assistant to help university students better understand their spending habits and improve budget management skills.

### Reflection
ChatGPT helped me identify useful financial-related features such as expense analysis, budgeting recommendations, savings recommendations, and CSV transaction processing.

I learned that it is important to clearly define business problems before writing code. This allowed me to focus on building a system that provides practical financial insights instead of simply displaying raw data.

---

## Entry 2 – CSV Data Processing

### Artifact
Used AI assistance to develop Python functions for loading and cleaning CSV transaction data.

### Context
The financial assistant needed to handle transaction files containing dates, amounts, categories, and descriptions. The data included real-world issues such as dollar symbols and refund values.

### Reflection
ChatGPT used pandas to help generate the initial data-cleaning logic. I implemented functions to remove dollar symbols, convert transaction amounts into numerical values, and remove invalid rows.

During the testing process, I learned the importance of data cleaning before performing analysis. I also improved my understanding of DataFrames and CSV processing in Python.

---

## Entry 3 – Spending Analysis

### Artifact
Developed spending analysis functionality using recommendations generated by pandas and AI.

### Context
I wanted the system to calculate total spending, spending by category, average transaction amount, and determine the highest spending category.

### Reflection
Artificial intelligence helped me build spending analysis logic using `groupby()` and aggregation calculations.

I tested the system with multiple transaction scenarios and learned how to generate business-focused insights instead of only technical outputs.

For example, the system identifies overspending areas such as entertainment or coffee expenses and generates simple financial recommendations based on spending patterns.

---

## Entry 4 – Financial Recommendation System

### Artifact
Used ChatGPT to generate financial recommendation logic.

### Context
This project required more than simple calculations. I wanted the assistant to provide practical financial advice to users.

### Reflection
I created recommendation logic based on spending categories and total spending levels.

For example, if entertainment expenses were the highest category, the system generated recommendations to reduce unnecessary spending and set monthly limits.

This helped me understand how business logic can improve user experience and make applications more useful for non-technical users.

---

## Entry 5 – Chatbot Personality Setup

### Artifact
Used artificial intelligence to create a personalised financial chatbot using AI packages.

### Context
I wanted the Smart Finance Assistant to communicate in a friendly and professional manner.

### Reflection
ChatGPT helped me design system prompts that focused on simple budgeting and savings advice.

I learned how prompts affect chatbot responses and how AI personality design can improve user interaction.

During testing, I also encountered connection and configuration issues with the AI server. I resolved these issues by checking the API configuration and re-running the setup cells.

This improved my debugging skills and understanding of AI integration workflows.

---

## Entry 6 – Simple RAG System

### Artifact
Built a simple retrieval-based financial advice system using keyword matching.

### Context
I wanted the chatbot to provide different financial advice based on the user’s questions.

### Reflection
I implemented a small RAG-style system using predefined financial prompts and keyword searches.

Examples included:
- Coffee → Savings advice
- Food and Groceries → Meal planning suggestions
- Transport → Travel cost reduction suggestions

Although this system is simple compared to advanced AI retrieval systems, it helped me understand the core idea of Retrieval-Augmented Generation (RAG).

I learned that retrieved context can improve chatbot responses and make answers more relevant to user questions.

---

## Entry 7 – Gradio User Interface

### Artifact
Used artificial intelligence to assist in creating a Gradio web interface for the Smart Finance Assistant.

### Context
I wanted users to upload CSV files and interact with the financial assistant through a simple interface.

### Reflection
ChatGPT helped me organise the Gradio layout using tabs, buttons, file uploads, and text boxes.

I successfully integrated:
- CSV analysis
- Spending recommendations
- Savings calculator

During development, I encountered several file upload and formatting issues, especially when uploading Excel files instead of CSV files.

I learned how file formats affect Python data processing and how debugging is an important part of software development.

---

## Entry 8 – Testing and Debugging

### Artifact
Created multiple testing scenarios using AI-generated test cases.

### Context
The project required proper testing to ensure that all functions worked correctly with different types of data.

### Reflection
I tested:
- Normal transaction data
- Refund scenarios
- Empty datasets
- Invalid values
- Savings calculator edge cases

I used assertion statements to validate results and confirm that calculations were correct.

During testing, several errors occurred, including:
- `NoneType` errors
- Empty sequence errors
- Incorrect file formats

By debugging these issues, I improved the reliability of the project and gained a better understanding of error handling in Python applications.
